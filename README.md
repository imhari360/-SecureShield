# 🛡️ SecureShield – Insurance Company Landing Page

Welcome to **SecureShield**, a modern and responsive insurance company landing page designed to showcase insurance services and help customers find the right coverage for their needs.

## 🌟 Features

- Modern and professional landing page design
- Responsive layout for mobile, tablet, and desktop
- Insurance plans and services section
- About Us and company information
- Why Choose Us section
- Customer testimonials and reviews
- Contact form for customer inquiries
- Frequently Asked Questions (FAQ)
- Call-to-action buttons
- Smooth animations and interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎨 Design

- Professional and trustworthy UI
- Clean layout with easy navigation
- Modern typography and responsive components
